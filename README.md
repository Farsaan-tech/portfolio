## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Farsaan-tech/portfolio.git
```

### Open the project

```bash
cd portfolio
```

Open `index.html` in your browser to view the website.

For local development, you can use Visual Studio Code with the Live Server extension.
